# Rabbit Pie 単4×2 電池内蔵ケース（一体型）

[Rabbit Pie](https://okikata.org/rp/index.html) の背面ケース
(`case_fix_2026.stl`) を改造し、下端を延長して **単4電池2本（直列 3V）を
そのまま搭載できる電池バーを一体化**したケースです。
これまでマジックテープで貼っていた電池ボックスは不要になります。

**追加の印刷部品はゼロ**（蓋なし・リベットなし・ネジなし）。
印刷するのはこの改造ケース1個だけで、十字キー・OLED マウントと合わせた
部品点数は増えません。

![preview](docs/preview.png)

## 設計のポイント

- **蓋のいらないスナップ保持** — 乾電池ホルダーと同じ方式で、チャンネル壁が
  電池を約220°包み込み、開口を電池径より 0.3mm 絞ってパチンと保持。
  電池はバネ側へ押し込んでから持ち上げれば外せる
- **印刷方法は従来と同一** — 電池バーの背面はケース背面と同一平面。
  これまでどおり背面を下にした平置き・サポート不要で印刷できる
  （造形高さ 13.3mm、追加体積は約 6cm³）
- **持ちやすい** — Game Boy 風の縦長シルエット（59.6×97.4mm）。
  下端バーの丸い電池の膨らみと 45° 面取りした両端タワーが
  パームレスト／指がかりになる
- **元の機能はそのまま** — PCB を留める四隅ポスト・スナップ爪・
  USB 切り欠き・軽量化穴はすべて無改造。改造カットは配線トンネル1箇所のみ

## 印刷設定の目安

- 材料: PLA / PETG
- 姿勢: 背面（平らな面）を下。**従来のケースと同じ**
- レイヤー 0.2mm、壁 3周、インフィル 15%、サポート不要
- 電池がきつい/ゆるい場合は `CELL_FIT`（チャンネル径の余裕）と
  `SNAP_PINCH`（開口の絞り量）を調整して再生成

## 必要な市販部品（電池端子バネ）

**注意:** 秋月電子は基本的に「プラスチックケース＋バネ＋リード線」が一体になった
**完成品の電池ボックス**しか扱っておらず、バネ端子だけを裸で単体販売している
コーナーはありません。入手方法は以下のどちらかになります。

### 方法A: 安い電池ボックスから端子だけ移植（もっとも簡単・確実）

秋月やモノタロウで**単4×2本 or ×3本のリード線付き電池ボックス**
（100〜200円程度）を1個買い、プラスチックケースを割って中の
バネ端子・平板端子（金具部分）だけを取り出して使う。
リード線が最初からハンダ付けされているのでそのまま流用できる。

### 方法B: バラの電池ばね端子を部品として買う

「電池ばね 板ばねタイプ」というカテゴリで、株式会社**アキュレイト**製が
MISUMI・モノタロウ・Amazon で購入できる（例: 型番 BS507 = 単3用マイナス極）。
単4(AAA)専用の型番はメーカーサイトの一覧で要確認:
https://www.accurate.jp/products_category/battery_sp_flat/
型番ごとに極性（＋/－）・電池サイズが決まっているため、
購入前に単4対応であることを型番表で確認すること。

### スロットが受け入れる実寸（型番によらず、これに収まればOK）

| 部位 | 上限 | 意味 |
|---|---|---|
| 差し込みタブ幅 | 10.8mm | タワー上部の縦スロット幅 |
| 差し込みタブ厚み | 1.0mm | スロットの隙間（板厚がこれ以下） |
| 差し込み深さ | 12.5mm | タワー上端〜床下0.8mmまでの通し穴長さ |
| タブ背後のふくらみ逃げ | +2.0mm | バネのコイル部・ハンダ端子折り返し用ポケット |
| 接点面同士の間隔 | 48.0mm | 電池(44.5mm) + バネ圧縮代3.5mm相当 |

一般的な単3/単4兼用の板ばね端子（幅9.5〜10mm、板厚0.3〜0.5mm、
コイル部径Φ8前後）であれば、ほぼ確実にこの範囲に収まる。
現物の実測値（幅・厚み・コイル径）が分かれば `generate_battery_case.py`
の `SLOT_W` / `SLOT_T` / `POCKET_T` をその値に合わせて再生成できる。

### 部品リスト

- マイナス側バネ電極 ×1、プラス側平板電極 ×1（リード線ハンダ付け用）
- 2本連結ブリッジ電極 ×1（無ければ単体電極2枚を銅線で接続）
- リード線 2本（AWG24–26、10cm 程度）

## 組み立て

1. **電極を差す** — 両端の「電極タワー」の縦スロットに電極を上から
   差し込むだけ。タワー上面に **＋／－ の刻印** があるので向きを合わせる
   - 右タワー（x+ 側）: ブリッジ電極（幅広スロット）
   - 左タワー（x- 側）: リード線付きの単体電極 ×2
2. **配線** — 左タワーの電極背面ポケットからリード線を下ろすと、
   電池室床の**配線ダクト**を通ってケース底壁の**貫通トンネル**
   （基板の下の空間に開口）からケース内部へ入る。
   これまで電池ボックスを繋いでいた電源入力へ接続する
3. **電池を入れる** — 上（前面側）からパチンと押し込むだけ。
   外すときはバネ側へ押してから端を持ち上げる

## 設計データ

```bash
pip install numpy trimesh manifold3d shapely
python3 generate_battery_case.py [元ケースSTL]
```

主な寸法:

| 項目 | 値 |
|---|---|
| チャンネル | Φ10.9（単4 Φ10.5 + 0.4）、電極面間 48.0mm |
| スナップ開口 | 10.2mm（0.3mm 絞り）、リップ包み込み角 約221° |
| 電池バー | 下方向へ +28.1mm、前面はリム +0.6mm（電池頂部は +3.4mm） |
| 電極タワー | 高さ z=9.33（電極高さ 12.5mm まで収容）、上面 45° 面取り |
| 配線トンネル | x −19〜−16 / z −2.8〜−0.6（コーナーポストと基板ハンダ面を回避） |

## 検証済み事項

- 出力 STL のメインシェルは watertight（ポスト・爪は元 STL のまま同梱。
  元ファイルと同じマルチシェル形式でスライサーが自動結合）
- 装着状態の単4セル（Φ10.5×44.5）はケースと干渉ゼロ、
  挿入途中のみリップと設計どおりの干渉（=スナップ）
- 配線トンネルは底壁を貫通し、四隅ポスト（x±21〜29）と
  基板下面ハンダ部（z>0.4）を回避
